# 🔧 メカニック計算ツール (Mechanic Calculator)

メカニック業務のための高機能な自動車修理・パフォーマンスカスタム見積もり・素材買取価格計算Webアプリケーションです。

---

## 🌟 主な特徴

- **店内 / 出張モード一括切り替え**: 画面上部のスイッチで「全修理」「エンジン」「ボディ」の単価を店舗用/出張用に一括切り替え。
- **金額数字の直隣にシンプルな統一コピーアイコン(`📋`)を配置**:
  - 【請求額 `¥1,000,000`】のすぐ右横に `📋` アイコンボタン（数値のみコピー）
  - 【金庫入金(3割) `¥300,000`】のすぐ右横に `📋` アイコンボタン（数値のみコピー）
- **右側のアクションエリア**:
  - **① 内容サマリ**: 例 `300000 全修理, エンジンLv3` (店内報告用)
  - **② 内容サマリ＋自車**: 例 `自車 300000 全修理, エンジンLv3` (自車修理カスタム申請・報告用)
- **ワンタップレベル選択**: 性能カスタム（エンジン、ブレーキ、サスペンション、トランスミッション、劣化抑制）を `[Lv1]` `[Lv2]` ... のボタン一発で選択。
- **従業員割引 30% OFF**: 従業員割引やカスタム値引き（% / 定額）をワンタップで計算。
- **一括リセット**: 次の車両の計算へ即座に移れる全選択リセット機能。
- **Renard-Repairスタイル**: 漆黒 × ネオンパープル / シルバーの洗練されたサイバーメカニックデザイン。

## 🚀 GitHub Pages での公開方法（手順）

本リポジトリはビルド不要の純粋なHTML/CSS/JavaScriptで構成されているため、数クリックで公開可能です。

1. このリポジトリを **GitHub** にプッシュします。
2. GitHubのリポジトリページを開き、上部メニューの **[Settings]** をクリックします。
3. 左側のサイドメニューから **[Pages]** を選択します。
4. **Build and deployment** セクションの **Source** を `Deploy from a branch` に設定します。
5. **Branch** を `main` (または `master`) / `/(root)` に設定し、**[Save]** をクリックします。
6. 数分待つと、画面上部に公開URL（例: `https://<ユーザー名>.github.io/soragon-mechanic-calculator/`）が表示されます！
